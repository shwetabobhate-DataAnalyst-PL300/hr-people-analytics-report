HR Analytics Dashboard 

Project Overview

This project showcases an end-to-end **HR Analytics Dashboard** built in **Power BI** to help HR professionals and business leaders monitor workforce performance through interactive visualizations and actionable insights. The dashboard transforms raw employee data into meaningful business intelligence, enabling data-driven decision-making across hiring, retention, and employee turnover.

Business Problem

Organizations often struggle to gain a consolidated view of workforce metrics. This dashboard addresses that challenge by providing a centralized view of key HR KPIs, helping stakeholders:

* Monitor workforce growth and headcount
* Measure employee retention and turnover
* Analyse hiring and exit trends
* Identify departments with higher attrition
* Support strategic workforce planning

Key Dashboard Features

Employee Headcount Analysis

  * Total Employees
  * Active Employees
  * Department-wise Headcount
  * Hiring Trends Over Time

Employee Retention Analysis

  * Employee Retention Rate
  * Year-over-Year Retention
  * Workforce Stability Metrics
  * Department-wise Retention Insights

Employee Turnover Analysis

  * Overall Turnover Rate
  * Voluntary vs. Involuntary Exits
  * Attrition Trends
  * Employee Departure Analysis
